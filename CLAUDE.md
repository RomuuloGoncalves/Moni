# Regras do projeto

## Commits

Nunca execute `git commit` (nem `git add` seguido de commit) neste repositório, em nenhuma branch, mesmo que uma fase de um plano/skill (ex.: tlc-spec-driven) normalmente termine com um commit atômico. Deixe todas as mudanças no working tree, sem commitar, e avise o usuário do que foi alterado para que ele revise e commite manualmente. Só faça commit se o usuário pedir isso explicitamente, na mesma conversa, para aquela mudança específica.
